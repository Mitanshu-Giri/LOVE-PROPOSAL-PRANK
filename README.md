# ❤️ Love Proposal Prank

A fun and interactive love proposal prank website built using HTML, CSS, and JavaScript.

The website asks the user a simple question: **"Do you love me?"** But there's a twist! The NO button keeps moving away whenever the user tries to hover over it, making it difficult to click. Clicking YES reveals a sweet thank-you message. ❤️

## ✨ Features

- Interactive YES and NO buttons.
- NO button moves to different positions when the cursor approaches it.
- A funny popup message appears while chasing the NO button.
- A hover message appears when hovering over the YES button.
- Displays a cute thank-you message after clicking YES.
- Romantic background image and simple UI.

## 🛠️ Technologies Used

- HTML5 – Structure of the webpage.
- CSS3 – Styling, layout, and visual effects.
- JavaScript – Button interactions and dynamic behavior.

## 🎮 How It Works

- Hover over the NO button and watch it escape!
- Keep chasing the NO button to trigger a funny popup.
- Hover over YES to see a message.
- Click YES to reveal the final love message.
